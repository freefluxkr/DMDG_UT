## 📖 Core Content
パンソリ春香家の中で最も有名な大木の一つである**「よもぎ毛」**について説明します。

1. 概要
「ヨモギの頭」は、春香が変学図の受け取りを拒絶し、翡翠に閉じ込められたまま、イム（イモンリョン）を懐かしく、自分の凄まじいお世話を嘆く内容を盛り込んでいます。春香街の「獄中歌」のうち白米に挙げられます。

2. タイトルの意味
「よもぎ毛」は「よもぎ畑のように乱れた髪」という意味です。刑務所で苦しみを経験し、長い間櫛をすることができずに混乱した春香の姿を象徴的に見せるタイトルです。

3.音楽的特徴
長団：主に真陽条長団と呼ばれます。チン・ヤンジョはパンソリ長団の中で最も遅い長団であり、春香の深い悲しみと絶望、そして切ない懐かしさを表現するのに適しています。

ジョー（道）：悲しい気持ちを与える界面組が主を成します。

4. 主な歌詞の内容
歌詞は春香の容貌描写から始まり、イモン龍に対する恨みと懐かしさ、そして死んでも会いたい切ない心につながります。

「よもぎ頭鬼形容積幕屋の冷たい席に思うからなだけだから…」
（よもぎ畑のような頭に幽霊のような形色で積み重ねた刑務所の冷たい床でただの考えだけだから…）

5. 有名なサウンド
この大木は日帝強占期の時期に臨滴銘唱が呼んで大衆的にすごい人気を得ました。当時、彼の声が盛り込まれたユ・ソンギのアルバムは、数万枚が売れるほど「ヨモギの頭の熱風」を起こし、今日でも国楽をよく知らない大衆に最も馴染みのある曲の一つです。
