# 🧠 KVJ V3 & 미래 지향적 웹사이트 기획 회의록

## 1. K-Virtual Journey V2/V3 글로벌 서비스 기획
- **스토리보드 완성**: 전체 7개 화면 와이어프레임 및 흐름 정의, NHK 스타일 상황극 UI 상세 설계 완료. ([[storyboard]])
- **서비스 구조 및 여정 설계**: IA 다이어그램 및 User Journey Map V2 작성, 데이터 플로우 다이어그램 정의 완료. ([[architecture_and_journey]])
- **WebView 앱 설계**: React Native Wrapper 기반 아키텍처 결정, 마이크/카메라 브릿지 인터페이스 설계. ([[webview_design]])
- **게이미피케이션 커뮤니티**: 포인트 획득/레벨링 시스템, 글로벌 스토리북 피드 및 랭킹 시스템 설계. ([[gamification_community]])

## 2. 미래 지향적(Futuristic) 웹사이트 데모 구축
- **발단**: 사장님의 `@local` 모델 프롬프트 지시 및 디자인 극대화 특명.
- **구현 결과 (KVJ V3: The Matrix)**:
  - **Preloader**: 접속 시 시스템 부팅 및 로컬 노드(gemma2:2b) 연결 연출.
  - **인터랙티브 파티클**: Canvas API를 활용한 우주 공간 신경망 시각화.
  - **마그네틱 버튼 & 커스텀 네온 커서**: 사용자의 마우스 움직임에 동적으로 반응하는 고급 UI.
  - **다이내믹 글로우**: 글래스모피즘 3D 틸트 카드에 마우스 좌표를 추적하는 손전등 이펙트 적용.

## 3. 지식 그래프 및 Second Brain 운영
- **이슈**: 초기 설정했던 회의록 자동 저장 규칙이 일시적으로 누락됨.
- **해결**: 본 회의록을 시작으로, 모든 중요 결정 사항과 태스크 완료 내역을 `.agent/knowledge_base/` 옵시디언 볼트에 마크다운 노드로 기록하여 지식 그래프(Knowledge Graph)를 다시 촘촘하게 엮어나가기로 함.
