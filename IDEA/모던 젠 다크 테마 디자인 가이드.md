# **모던 젠(Zen) 다크 테마 디자인 가이드**

## **1\. 모던 젠(Zen) 다크 테마란?**

단순한 칠흑색(\#000000) 화면이 아닌, 자연에서 영감을 받은 부드러운 어둠과 충분한 비움(여백)을 통해 **시각적 공해를 최소화하고 사용자에게 깊은 몰입감과 정서적 평온함을 주는 디자인 스타일**입니다.

정보의 과잉 공급에 지친 현대인들에게 디지털 공간 안에서 일종의 '명상실'과 같은 차분한 경험을 제공합니다.

## **2\. 핵심 디자인 요소 (Core Elements)**

### **① 색상 계획 (Organic & Muted Colors)**

자연의 돌, 흙, 모래, 밤하늘에서 가져온 유기적인(Organic) 색조를 사용하여 차갑지 않고 따뜻한 온기가 느껴지는 어둠을 표현합니다.

* **배경색 (Background):**  
  * 새까만 블랙 대신, 깊은 밤하늘이나 젖은 돌의 느낌을 주는 딥 차콜, 어두운 슬레이트 그레이, 혹은 미세하게 녹색/청색이 감도는 무채색을 사용합니다.  
  * *예시 색상:* Slate-950 (\#090d16), 짙은 잉크색 (\#0d1117)  
* **주요 텍스트 (Primary Text):**  
  * 눈부심을 유발하는 순수한 흰색(\#ffffff)을 피하고, 약간의 온기가 섞인 미색(Warm White)이나 아주 밝은 베이지를 사용합니다.  
  * *예시 색상:* 크림색 (\#f5f5f0), 연한 미색 (\#e2e8f0)  
* **포인트 색상 (Accent Color):**  
  * 화려한 네온 컬러나 형광색은 배제합니다. 은은한 백사장의 모래색(Sand Sand), 차분한 대나무의 녹색(Bamboo Green), 또는 촛불의 따뜻한 오렌지빛(Soft Amber)을 포인트로 삼습니다.  
  * *예시 색상:* 빛바랜 올리브 녹색 (\#8fa89b), 차분한 금색 (\#d4af37)

### **② 여백의 미 (Negative Space & Yohaku)**

* 화면에 너무 많은 정보나 아이콘을 빽빽하게 채워 넣지 않습니다.  
* 텍스트와 버튼 사이에 **과감할 정도로 넓은 여백**을 두어 화면 전체가 숨을 쉴 수 있게 만듭니다.  
* 여백 자체가 디자인의 완성도를 결정하는 중요한 요소가 됩니다.

### **③ 타이포그래피 (Elegant & Readable Typography)**

* 본문은 가독성이 높고 단정한 고딕(Sans-serif) 계열을 사용하되, 감성을 자극하는 제목이나 마중물 문장에는 우아한 명조(Serif) 계열의 서체를 사용하여 문학적인 감성을 극대화합니다.  
* 줄 간격(Line-height)과 자간(Letter-spacing)을 일반 앱보다 넓게 설정하여 천천히 음미하며 읽을 수 있는 리듬감을 부여합니다.

## **3\. '당목담글' 적용 시나리오 (UI Concept)**

'당목담글'의 핵심 화면인 "오늘의 마중물 낭독(기부) 화면"을 모던 젠 다크 테마로 구성했을 때의 비주얼 콘셉트입니다.

\+------------------------------------------+  
|  \[설정\]                          \[내 서재\]  |  
|                                          |  
|                                          |  
|        " 비는 대지를 적시고,             |  \<-- 명조체 (Serif)의 따뜻한 미색 글씨  
|          내 목소리는 당신의              |      충분한 행간으로 시적 연출  
|          마음을 적십니다. "              |  
|                                          |  
|                                          |  
|                   ( )                    |  \<-- 아주 부드럽게 깜빡이는 녹음 버튼  
|                 \[ 마이크 \]               |      진동이나 화려한 애니메이션 배제  
|                                          |  
|                                          |  
|  \[나의 데이터는 온전히 이 기기에 보관됩니다\]  \<-- 신뢰감을 주는 정중하고 투명한 안내문  
\+------------------------------------------+

### **UX 가이드라인:**

1. **정적인 전환 애니메이션:** 화면이 바뀔 때 빠르게 슥 지나가는 것이 아니라, 안개가 걷히듯 아주 부드럽게 서서히 나타나는 페이드 인/아웃(Fade-in/out) 효과를 사용합니다.  
2. **사운드 피드백:** 마이크 버튼을 누를 때 삑- 하는 날카로운 기계음 대신, 가볍고 맑은 종소리(Tibetan Bowl)나 조용한 똑 소리 같은 자연스러운 소리를 적용합니다.  
3. **산만함 제거 (Distraction-Free):** 녹음이 진행될 때 파동 형태의 화려한 스펙트럼 애니메이션을 보여주기보다는, 화면 전체의 빛이 숨을 쉬듯 아주 느리게 밝아졌다 어두워지는 단순한 빛의 파동 효과를 제공하여 사용자가 오직 '글의 낭독과 내 목소리'에만 집중할 수 있게 돕습니다.
