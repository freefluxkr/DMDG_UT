# 작업지시 002: 이미지 폴더 경로 수정 및 빈 컷 에러 핸들링

## 1. 사장님(USER)의 요청 사항
* **상황**: 롱폼 영상에 17컷 이후 이미지가 없음. `webtoon_30cuts` 폴더 안에는 Act3의 `016_cut16.png`까지만 존재함.
* **이슈 제기**: 렌더링 스크립트가 새로 만든 폴더가 아닌 구형 `webtoon` 폴더(전통 해태 이미지)를 참조하고 있다는 사실을 사장님이 먼저 짚어주심.

## 2. 데미스(AI)의 조치 내용
* `render_video_30cuts.py` 내의 이미지 참조 경로를 `YOUTUBE\result\webtoon_30cuts`로 즉시 수정.
* **에러 핸들링 추가**: 현재 구글 이미지 생성 쿼터가 만료되어 17컷부터 30컷까지의 이미지가 없는 상태이므로, 에러를 내뿜지 않고 오디오 길이에 맞춰 까만 화면(`black.png`)이 나오도록 임시 예외 처리 로직 적용.
* 수정된 스크립트로 파이프라인 무결성 1차 검증 완료.
