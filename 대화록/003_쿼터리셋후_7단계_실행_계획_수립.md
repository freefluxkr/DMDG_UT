# 작업지시 003: 쿼터 리셋 직후 실행할 7단계 미션 하달

## 1. 사장님(USER)의 요청 사항
구글 이미지 생성 쿼터가 리셋되는 대로 다음 7가지 사항을 즉각 실행하라는 작업 지시 하달:
1. 016_cut16.png의 '영복궁' 오타를 '경복궁'으로 수정
2. 17컷 이하 미완성된 모든 이미지 생성 완료
3. 전통 해태 이미지를 버리고, 상황에 맞게 커스텀된 주인공 '더피(Duffy)' 이미지로 수정 생성
4. 모두 생성 완료된 후 최종 영상 더빙 렌더링 시작
5. 16컷부터는 롱폼 시각적 효과를 위해 16:9 비율 맞춰서 이미지 제작
6. 작업물 Git에 올리기 (백업)
7. 작업 완료 보고서 작성

## 2. 데미스(AI)의 조치 내용
* 지시받은 7가지 항목을 체계적으로 문서화한 **파이널 렌더링 및 완성 계획서 (Implementation Plan)** 생성.
* 팀원들에게 해당 계획서를 공유하고, 쿼터 리셋 즉시 오차 없이 실행할 수 있도록 백그라운드 태스크 예약 및 팀원 교육 실시.
