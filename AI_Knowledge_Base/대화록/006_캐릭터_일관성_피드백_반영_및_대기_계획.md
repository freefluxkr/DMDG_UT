# 작업지시 006: 캐릭터 일관성 피드백 반영 및 구글 쿼터 복구 대기 계획

## 1. 사장님(USER)의 요청 사항
* **정체성 및 일관성 오류 지적**: 17~25컷에서 더피의 정체성이 사라지고 단순 포즈만 나오며, 30컷의 단체 샷 캐릭터들도 소유하고 있는 오리지널 캐릭터들이 아니라고 지적하심.
* **시나리오 싱크 부족**: 기존 스토리보드 시나리오와 연출이 맞지 않는 점을 확인하심.
* **출력 파일명 구분 지시**: 최종 영상 더빙본 렌더링 시 기존 프리뷰 파일에 덮어쓰지 말고 새로운 파일명으로 구분하여 저장할 것을 지시하심.
* **주인공 캐릭터 파일 매핑 지시**: `characters` 폴더 안의 파일명(더피.png, 서씨.png, 바비.jpg 등)이 곧 주인공들의 모습(정체성)을 나타내고 있으므로, 이미지 생성 시 이를 적극 연동하고 참고할 것을 지시하심.
* **로고 응용 여부 문의**: `당목담글` 로고 이미지의 영상/에셋 내 적용 가능성 및 응용 범위에 대해 질문하심.
* **쿼터 낭비 질책**: 불완전한 결과물로 인해 구글 쿼터 한도와 시간이 무의미하게 소모된 부분에 대해 강하게 질책하심.

## 2. 데미스(AI)의 조치 내용
* **진심 어린 사과 및 반성**: 잘못된 우회 방식으로 인해 사장님의 쿼터와 소중한 시간을 낭비한 것에 대해 진심으로 사과하고 깊이 반성함. 향후 절대 타협하거나 성급한 대체안을 쓰지 않고 오직 검증된 방식으로 고품질을 지향하기로 다짐함.
* **우회 생성 시도 중단**: 공공 API(Pollinations AI)가 캐릭터 시트의 원본 에셋을 읽지 못해 빚어진 캐릭터 정체성 유실 문제로 판단하고, 단순 우회 생성을 즉시 중단함.
* **정공법 계획 수립**: 구글의 공식 이미지 생성 쿼터가 리셋되는 시간인 **오늘 밤 10시 55분(22:55:34)** 이후에 공식 도구를 활용하기로 결정.
* **참조 이미지 설계**: `generate_image` 기능의 `ImagePaths` 인자에 로컬 캐릭터 원본 에셋(`더피.png`, `서씨.png`, `강하루.jpg` 등)을 직접 매핑하여 캐릭터 외형 일관성을 원천 확보함.
* **스토리보드 싱크 프롬프트 구체화**: 놀람, 슬픔, 눈물, 영혼 오버랩 등의 세부 시나리오 액션을 녹인 정교한 프롬프트 10종을 설계하여 수정 계획서(Implementation Plan)에 반영함.
* **렌더러 파일명 수정**: `YOUTUBE\render_video_30cuts.py` 스크립트를 수정하여 최종 완성본의 출력 파일명을 기존 프리뷰 파일(`longform_30cuts_{lang}_preview.mp4`)을 덮어쓰지 않도록 `longform_30cuts_{lang}_final.mp4`로 저장되도록 로직을 조치함.
* **Git 상태 확인**: 사장님의 Git 작업 가능 여부 문의에 따라, 시스템 PATH에 없던 Git 실행 파일 경로(`C:\Program Files\Git\cmd\git.exe`)를 찾아내어 `git status`를 통한 작업 상황(코드 변경점, 대화록, 로고 원본 등) 확인을 완료함.
* **대기 상태 전환**: 사장님의 엄명에 따라, 구글 쿼터 리셋 직후 어떠한 오류도 없이 즉각 실행될 수 있도록 모든 리소스를 대기시킴.
