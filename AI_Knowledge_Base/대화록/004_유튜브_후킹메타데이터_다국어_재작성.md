# 작업지시 004: 유튜브 후킹 메타데이터 3개국어 번역 및 더피 설정 반영

## 1. 사장님(USER)의 요청 사항
* **상황**: 기존에 작성된 후킹/어그로 해시태그 설명글 파일을 찾을 수 없음.
* **요구**: 해당 파일을 찾아, 기존 일반 '해태' 설정을 주인공 '더피(Duffy)'로 업데이트하고 3개국어(KOR, ENG, JPN)로 다시 작성하여 열어줄 것.

## 2. 데미스(AI)의 조치 내용
* `003_youtube_upload_metadata_v2.md` 파일을 발굴하여 내용 전면 개편.

* 사장님이 쉽게 확인할 수 있도록 아티팩트 링크로 제공.
