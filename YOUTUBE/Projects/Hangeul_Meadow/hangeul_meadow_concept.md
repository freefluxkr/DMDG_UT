# 프로젝트 기획서: 한글 초원 (Hangeul Meadow)

**작성자**: 페기 (Peggy)
**프로젝트 단계**: Phase 1 (유튜브 애니메이션), Phase 2 (인터랙티브 앱 배포)

## 1. 프로젝트 개요 (Concept)
*   **테마**: 클레이(점토), 나무, 천 등 따뜻한 질감의 애니메이션 감성.
*   **배경**: 햇살 가득한 평화로운 '한글 초원'. 부드러운 언덕과 거대한 잉크병 모양의 건물이 있는 마을.
*   **핵심 내용**: 자음과 모음이 의인화되어 서로 돕고 협력하며 다양한 단어를 만들고, 단어가 모여 문장이 되고 마을이 확장되는 과정을 담은 마법 같은 힐링 콘텐츠.

## 2. 캐릭터 디자인 (Characters)
*   **기억이 (ㄱ)**: 오크 나무 질감의 따뜻하고 단단한 캐릭터.
*   **아야 (ㅏ)**: 부드러운 린넨 천 질감의 포근한 캐릭터.
*   **니은이 (ㄴ)**: 말랑말랑한 점토 질감의 캐릭터.
*   *기타 자음/모음들도 각자의 고유한 따뜻한 질감을 가짐.*

## 3. 핵심 연출 포인트 (Directing)
1.  **결합의 마법**: '기억이(ㄱ)'와 '아야(ㅏ)'가 마주 볼 때 황금빛 마법 가루가 흩날리며 단어 **'가'**로 변신.
2.  **의미의 시각화**: 만들어진 단어는 그 의미에 맞는 실체로 변함. (예: '나비' 글자가 진짜 나비가 되어 날아감, '나무' 글자 자리에 튼튼한 나무가 자라남).
3.  **사운드 인터랙션**: 단어 완성 시 맑고 명확한 발음이 효과음과 함께 출력.
4.  **자막 및 교육 효과**: 화면 하단에 만들어진 단어의 뜻과 예시 자막이 부드럽게 표시됨.

## 4. 단계별 진행 계획 (Phases)
### Phase 1: 유튜브 영상 제작 (단편 시리즈)
*   **첫 번째 에피소드**: 자음과 모음의 첫 만남과 자기소개. 
*   **상징 단어 완성**: 여러 자음/모음이 협력하여 우리의 정체성을 알리는 단어 **'당목담글'**을 최초로 완성하는 감동적인 연출.

### Phase 2: 배포 가능한 교육/힐링 앱 (App Development)
*   사용자가 직접 자음과 모음 캐릭터를 드래그 앤 드롭하여 결합하고 마법 연출(사운드/시각화)을 체험할 수 있는 인터랙티브 앱 제작.
