# 파이썬 GUI 프로그래밍 실습 과정 (Python GUI Programming Course)

이 저장소는 수강생들이 **파이썬 GUI 프로그래밍**을 체계적으로 배울 수 있도록 구성된 실습 및 강의 자료 저장소입니다.
각 장별 강의 자료는 광고가 완전히 제거된 PDF 파일로 포함되어 있으며, 실습용 파이썬 스크립트(.py) 파일들이 장별로 준비되어 있습니다.

---

## 📂 실습 과정 구조

* **[00_Introduction](./00_Introduction)** - 00장. 들어가기 전에 (개요 및 소개)

* **[03_tkinter_Advanced](./03_tkinter_Advanced)** - 03장. tkinter 심화 (상태 바인딩, OOP, MVP 패턴 및 스레드)
* **[04_tkinter_Practice](./04_tkinter_Practice)** - 04장. tkinter 실전 (타이머 앱, 연락처 앱, 네트워크 점검)

* **[06_PySide6_Advanced](./06_PySide6_Advanced)** - 06장. PySide6 심화 (Qt Designer, 모델/뷰 아키텍처, 스타일링, 멀티스레딩)

## 🚀 시작하기
1. 각 단원의 **`.pdf` 교재 파일**을 열어 이론 내용과 코드를 확인합니다.
2. 폴더 내부에 자동 생성된 실습용 **`.py` 소스코드 파일**을 열어 실습 코드를 직접 작성하고 실행합니다.
